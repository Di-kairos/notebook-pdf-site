Notebook PDF

Support · Mac

Notebook PDF turns a Jupyter notebook (.ipynb) into a PDF you can send as is: wide tables stay readable, formulas are typeset, plots stay in place.

Make a PDF

  1. Open a notebook: choose it in the Open window, drag it onto the app, or double-click it in Finder.
  2. Pick the layout in the toolbar: Show Code, Title Page, A4 or US Letter. The preview shows the exact PDF.
  3. Click Export and choose where to save.

A plot or output is missing

Notebook PDF doesn't run code. It uses the outputs saved in the notebook, so run the notebook and save it before opening it here. Interactive charts are exported as their saved static image; without one, the PDF shows a short note in their place.

The file won't open

Notebook PDF reads notebooks in nbformat 4 up to 100 MB. The window says what's wrong with a file it can't read. If a valid notebook fails, write to us and attach it if you can.
